# Security Hardening (PR Group 5: BUG-46, BUG-47, BUG-48) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close three security holes: symlink escape of the media root (BUG-46), unauthenticated network exposure by default (BUG-47), and config `path` entries escaping the data directory plus a panic-instead-of-error in `MediaLoader::new` (BUG-48).

**Architecture:** All media-path validation lives in `src/media/load.rs` (`MediaLoader`, used by the `/file/` handlers in `src/cmd/drill/server.rs` and `src/cmd/serve/handlers.rs`) and `src/media/resolve.rs` (`MediaResolver`, used at collection-load time). The fix canonicalizes joined paths and requires them to stay under the canonicalized root. Bind-address defaults live in `src/cmd/serve/config.rs` (`default_host`) and `src/cli.rs` (clap `default_value`). Config collection paths are validated lexically in `ResolvedServeConfig::from_toml` before they are joined onto the repo dir.

**Tech Stack:** Rust, cargo, axum, serde/toml, clap. Tests are plain `#[test]` unit tests with `tempfile` via the existing `create_tmp_directory()` helper.

**Spec:** SPEC.md

## Global Constraints

Copied verbatim from SPEC.md "Global requirements" (apply to every item below, from `CLAUDE.md`):

- Every bugfix starts with a failing regression test.
- No `unwrap()` in production code; use `Fallible`, `?`, and `fail()`.
- All error messages are user-facing and clear.

Additional project rules relevant here (from `CLAUDE.md`): prefer imports over fully qualified names; keep functions small; tests may use `unwrap()`/`panic!`; dates are naive on purpose (not relevant to these tasks).

```rust
    /// Given a path string from the client, check that a file exists at that
    /// location within the collection root directory.
    ///
    /// Symbolic links and absolute paths are rejected, and the canonicalized
    /// path must remain inside the canonicalized collection root, so a
    /// symlinked directory cannot be used to escape it.
    pub fn validate(&self, path: &str) -> Result<PathBuf, MediaLoaderError> {
        let path: PathBuf = PathBuf::from(path);
        if path.components().any(|c| c == Component::ParentDir) {
            return Err(MediaLoaderError::ParentComponent);
        }
        if path.is_absolute() {
            return Err(MediaLoaderError::Absolute);
        }
        let path: PathBuf = self.root.join(path);
        if !path.exists() {
            return Err(MediaLoaderError::NotFound);
        }
        if path.is_symlink() {
            return Err(MediaLoaderError::SymbolicLink);
        }
        let canonical_root: PathBuf = self
            .root
            .canonicalize()
            .map_err(|_| MediaLoaderError::NotFound)?;
        let canonical: PathBuf = path
            .canonicalize()
            .map_err(|_| MediaLoaderError::NotFound)?;
        if !canonical.starts_with(&canonical_root) {
            return Err(MediaLoaderError::OutsideRoot);
        }
        if !canonical.is_file() {
            return Err(MediaLoaderError::NotFile);
        }
        Ok(canonical)
    }
```

Note the check order is load-bearing: the `is_symlink()` check on the joined (non-canonical) path keeps the existing `test_symlink` behavior (a symlink as the *final* component is still rejected as `SymbolicLink`); canonicalization then catches symlinked *intermediate* directories.

```rust
                        entry.path
                    ));
                }
                let slug = entry.slug();
                Ok(ResolvedCollection {
                    name: entry.name.clone(),
                    coll_dir: repo_dir.join(&entry.path),
                    db_path: db_dir.join(format!("{slug}.db")),
                    slug,
                })
            })
            .collect::<Fallible<Vec<ResolvedCollection>>>()?;
```

(`fail` is already imported in this file; `repo_dir` is in scope, defined a few lines above. Because the path is now guaranteed relative with no `..` components, `repo_dir.join(&entry.path)` can no longer escape the data directory. With `Path::join`, an absolute right-hand side *replaces* the left-hand side entirely — that was the hole.)
